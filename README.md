## 💡 Overview
**AlibiGraph** is a cyber-forensic web application built to untangle complex event logs, trace digital footprints, and map digital alibis using graph-based intelligence. It helps investigators instantly parse data, visualize relationships, and uncover key timelines through an intuitive browser interface.



## ✨ Key Features
* 📊 **Graph-Based Forensics**: Automatically map entities, events, and timelines to uncover hidden connections.
* 🎛️ **Interactive Control Strip**: Dynamic parameter tweaking and custom credential configurations directly from the UI.
* ⚡ **Real-Time Log Processing**: Fast parsing engine built to handle event datasets efficiently.
* 🌐 **Cloud-Native Deployment**: Accessible instantly via a live public URL with zero local installation overhead.



## 🛠️ Tech Stack & Architecture
* **Frontend & Backend**: Streamlit (Python)
* **Data Visualization & Graphing**: NetworkX, Pandas, Plotly
* **Hosting**: Streamlit Community Cloud



## 🚀 Quick Start (Run Locally)

If you want to run AlibiGraph locally on your machine, follow these steps:

1. Clone the repository:
   git clone [https://github.com/NotADIM2/AlibiGraph.git](https://github.com/NotADIM2/AlibiGraph.git)
   cd AlibiGraph
2.Install Dependencies
   pip install -r requirements.txt
3.Run The Application
   streamlit run app.py
